# AI-дайджест для клиентов ЛОР-врача

Конверсионный сайт на Flask. AI-дайджест с 10 готовыми карточками с кнопкой "Открыть материал". Современный яркий, не шаблонный, тёмный фон, красивые цвета, плавные переходы. Адаптирован под телефон и компьютер.

## Стек
- Flask
- HTML
- CSS
- JavaScript

## Запуск
```bash
pip install -r requirements.txt
python app.py
```

Сайт откроется по адресу: http://localhost:5000
